# Ventora Brand Guidelines

Ultima decision consolidada: 2026-05-24

## Objetivo de marca

Ventora debe percibirse como una marca solida, memorable, moderna y comercial para empresas de vidrios y aluminio.

La marca no debe sentirse como:

- ERP
- software de produccion
- cotizador tecnico puro
- industria pesada o fabrica
- SaaS generico blanco/azul

La marca si debe transmitir:

- captacion de leads
- orden comercial
- rapidez para responder
- profesionalismo
- confianza
- cierre de trabajos

## Decision oficial del logo

La marca principal de Ventora es:

- isotipo `V + cubo`
- junto al wordmark `VENTORA`

Reglas:

- el cubo solo no es la marca principal
- el cubo solo puede usarse como recurso secundario, fondo, marca de agua o apoyo visual
- el icono de app, PWA o movil puede usar una version compacta mas impactante con la `V` dominante
- no usar el cubo dentro de la letra `O` de `VENTORA`
- el isotipo siempre debe ir fuera de la palabra
- usar SVG siempre que sea posible

## Sistema de logo

### 1. Logo principal horizontal

Uso oficial por defecto:

- `V + cubo + VENTORA`

Debe sentirse:

- premium
- moderno
- sobrio
- legible
- corporativo
- vinculado a vidrio y aluminio sin exageracion

### 2. Isotipo para avatar y redes

Uso secundario:

- `V + cubo`

Ideal para:

- avatar
- redes
- favicon grande
- foto de perfil
- sello visual breve

### 3. Icono de app o PWA

Uso compacto:

- version con `V` dominante dentro de una composicion mas contundente

Objetivo:

- maxima legibilidad en tamanos pequenos
- alto reconocimiento en movil

### 4. Version secundaria monocroma

Mantener:

- una version clara para fondos oscuros
- una version oscura para fondos claros

No agregar:

- 3D excesivo
- brillos artificiales
- volumen innecesario en contextos funcionales

## Tipografia del wordmark

La tipografia debe ser:

- sans-serif
- geometrica
- limpia
- robusta
- corporativa
- muy legible

Evitar:

- fuentes futuristas extremas
- tipografias delgadas
- estilos experimentales
- trazos fragiles o demasiado decorativos

## Paleta oficial

- negro premium: `#050505`
- negro azulado: `#0B0F17`
- grafito oscuro: `#111827`
- azul electrico: `#1E88FF`
- plata metalica: `#E6E8EB`
- gris acero: `#8A96A6`

## Regla de uso por canal

### Marketing, redes, videos, portadas y afiches

Usar:

- fondos oscuros
- presencia fuerte del logo
- negro premium dominante
- contraste alto
- azul electrico puntual

Buscar:

- impacto visual
- autoridad
- seriedad
- valor percibido

### Landing page

Usar:

- matices de negro
- grafito
- negro azulado

Evitar:

- negro plano absoluto en toda la interfaz
- look generico de SaaS blanco/azul

### App interna

Regla explicita:

- puede mantener una linea mas clara y funcional si mejora legibilidad y productividad
- no forzar la paleta oscura de branding dentro del sistema autenticado
- no tocar colores internos del sistema salvo pedido explicito y QA aparte

### Login y piezas institucionales

Usar cuando convenga:

- fondo oscuro premium
- imagen o textura relacionada con vidrio o aluminio

Condicion:

- no sacrificar rendimiento, claridad ni conversion

## Imagenes

Priorizar:

- fachadas de vidrio
- perfiles de aluminio
- arquitectura moderna
- planos tecnicos
- oficinas sobrias
- proyectos terminados

Evitar:

- servidores
- robots
- IA generica
- tecnologia abstracta sin relacion con el rubro
- stock barato o poco creible

## CTA

Regla:

- CTA principal: `#1E88FF`
- CTA secundario: oscuro o transparente con borde sutil
- WhatsApp: verde solo en accion directa de WhatsApp, no como color principal de marca

## Espaciado, tamanos y consistencia

Mantener siempre:

- area de respiro suficiente alrededor del logo
- separacion clara entre isotipo y wordmark
- proporcion consistente entre icono y texto
- version simplificada para tamanos pequenos

Evitar:

- comprimir el wordmark
- pegar el isotipo a la palabra
- deformar el logo
- rasterizar el logo cuando puede ir en SVG
- mezclar versiones distintas del logo en una misma pieza

## Produccion esperada

Toda propuesta de branding de Ventora debe poder producir o respetar:

1. logo principal horizontal `V + cubo + VENTORA`
2. isotipo para avatar y redes `V + cubo`
3. icono de app/PWA con `V` dominante
4. version secundaria monocroma para fondos claros y oscuros
5. reglas de espaciado, tamano minimo y consistencia
6. aplicacion coherente en landing, marketing, login y redes

## Restricciones finales

- no volver la marca demasiado tecnica o fabril
- no usar demasiados efectos 3D en la version funcional del logo
- no mezclar lenguajes visuales distintos entre landing, marketing y branding
- no romper la percepcion premium, sobria y comercial
- no comprometer claridad mobile-first
