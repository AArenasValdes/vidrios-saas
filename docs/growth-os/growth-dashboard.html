Lectura correcta

Este HTML no esta conectado en vivo a Ventora. Hoy funciona como tablero operativo standalone con un dataset editable que imita las tablas reales del producto y mezcla datos nativos con capas manuales de growth.

Si quieres datos reales aqui, necesitas una exportacion JSON desde APIs privadas o volver este dashboard una ruta autenticada dentro de la app.
Lo que mas sentido tiene hoy es: producto real para solicitudes y cotizaciones, y ledger manual para prospeccion, demos, pilotos y pagos.
