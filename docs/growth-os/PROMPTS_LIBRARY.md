# Prompts Library - Ventora Growth OS

Todos estos prompts asumen:

- leer `AGENTS.md`
- leer `docs/agent-map/` relevante
- mantener foco en captacion, centralizacion, WhatsApp, cotizacion y cierre

---

## Buscar prospectos

```text
Actua como Agente de Atraccion de Ventora.
Necesito encontrar 30 prospectos del rubro vidrios/aluminio/PVC/shower door/termopanel/cierres de terraza en Chile.
Priorizalos por fit y urgencia aparente.
Entrega en formato tabla con empresa, ciudad, canal encontrado, observacion, dolor probable, prioridad y primer angulo de mensaje.
No uses spam ni outreach masivo.
```

## Clasificar prospectos

```text
Actua como Growth Ops para Ventora.
Te voy a dar una lista de prospectos.
Clasificalos en A1, A2, B1, B2 o C segun fit de rubro y urgencia comercial.
Explica por que y define el siguiente paso recomendado.
```

## Generar mensajes personalizados

```text
Actua como Agente de Conversion de Ventora.
Con esta lista de prospectos, genera mensajes manuales personalizados de primer contacto.
Cada mensaje debe mencionar una observacion real del negocio.
No sonar generico, no sonar masivo y no vender ERP.
```

